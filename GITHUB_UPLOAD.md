# Publish this portfolio on GitHub

## Before publishing

Confirm that you are permitted to publish an anonymized description of work completed for your employer. The included templates remove production configuration, but company approval should still take priority.

## Recommended repository settings

- **Repository name:** `business-operations-automation-portfolio`
- **Description:** `Anonymized n8n case studies integrating Microsoft 365, SQL databases, REST APIs, Salesforce, and AWS messaging.`
- **Visibility:** Start as Private, review it, then change to Public when approved.
- **Initialize with README:** No. This folder already contains a README.
- **License:** Leave unset unless you are authorized to open-source the templates.

## Easiest method: GitHub Desktop

1. Install and sign in to GitHub Desktop.
2. Select **File → Add Local Repository**.
3. Choose the `github-automation-portfolio` folder.
4. If GitHub Desktop says the folder is not a repository, select **Create a repository**.
5. Use `business-operations-automation-portfolio` as the repository name.
6. Confirm that all files are listed under **Changes**.
7. Enter this commit message:

   `Add anonymized business automation portfolio`

8. Select **Commit to main**.
9. Select **Publish repository**.
10. Keep **Private** selected for the first review.
11. After reviewing the GitHub pages and receiving any required approval, change the repository visibility to Public.

## Add repository topics

On the repository page, edit the **About** section and add:

`n8n` `workflow-automation` `business-process-automation` `api-integration` `salesforce` `sql-server` `mysql` `microsoft-365` `aws-sqs`

## Feature it on your GitHub profile

1. Open your GitHub profile.
2. Select **Customize your pins**.
3. Select `business-operations-automation-portfolio`.
4. Save the selection.

If you have a GitHub profile README, use the content in [GITHUB_PROFILE_SNIPPET.md](GITHUB_PROFILE_SNIPPET.md).
