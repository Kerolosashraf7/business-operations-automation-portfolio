# Copy-ready project descriptions

These descriptions can be used in a GitHub profile, LinkedIn Projects section, CV, or portfolio website.

## Bulk Feedback Publication Automation

Designed an email-driven n8n workflow that validates authorized CSV requests, deduplicates and validates record identifiers, applies a controlled bulk SQL update, and sends one result notification to the requester. Added sender, subject, attachment, file-size, numeric-input, and maximum-volume safeguards to prevent unsafe database changes.

**Skills:** n8n, Microsoft Outlook, CSV processing, Microsoft SQL Server, input validation, bulk operations, email automation, security controls, error handling.

## Reviews and Ratings Migration Automation

Built a multi-request n8n workflow that reads approved migration requests from Excel, resolves source and destination profiles, copies review data through an API, safely migrates rating records, verifies the final database state, and publishes a search-refresh message. Implemented duplicate prevention, transactional inserts, checkpoint-based recovery, retry handling, blocked-request routing, and business-facing status updates.

**Skills:** n8n, Microsoft Excel 365, SQL Server, REST APIs, AWS SQS, transactional SQL, idempotency, checkpointing, retry design, batch processing, production troubleshooting.

## Doctor Profile Ranking Operations Automation

Developed an event-driven n8n workflow that accepts bulk ranking requests through a shared mailbox, validates and processes every CSV row, updates and verifies MySQL state, synchronizes an API, optionally updates Salesforce, and sends one consolidated result file and summary. The workflow supports two business actions while keeping each email and row isolated.

**Skills:** n8n, Microsoft Outlook, CSV processing, MySQL, REST APIs, Salesforce, OAuth 2.0, event-driven automation, aggregation, conditional integrations, error reporting.

## Sandbox Account Provisioning Automation

Built an email-driven n8n workflow that receives sandbox CSV account requests through Microsoft Outlook, validates required user attributes, provisions test accounts through a REST API, and replies with a consolidated row-level success and failure report. Added case-insensitive subject matching, attachment selection, per-email isolation, batch throttling, HTTP response validation, and safe test-only defaults.

**Skills:** n8n, Microsoft Outlook, Microsoft Graph, CSV processing, REST APIs, account provisioning, input validation, batch processing, response validation, error reporting.
